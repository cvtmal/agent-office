# transcripts: small synthetic transcript cases for reader unit tests; cycle #1.

Generated by `fixtures/gen/transcripts.ts` (`make fixtures`); do not edit by hand. `test/fixtures.test.ts` checks the bytes.

- `cases/<name>.jsonl` — one transcript per rule, named after what it covers (`status-*`, `tokens-*`, `health-*`, `names-*`, `activity-*`, `secrets`). Expectations: `test/reader-fixtures.test.ts`.
- `config/` — a fake Claude config dir: `projects/<slug>/<session>.jsonl`, `…/<session>/subagents/[<dir>/]agent-<id>.{jsonl,meta.json}`, `…/<session>/custom-title.json`, registry `sessions/<pid>.json` (+ a non-registry file). Slug = cwd with `/` and `.` → `-`.
- `ps.txt` — a fake `ps -axo pid=,lstart=,command=` table for those pids (one reused pid, one teammate, unrelated processes).
